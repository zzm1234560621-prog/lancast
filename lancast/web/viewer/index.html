证书说明

浏览器提示证书警告是正常的：LanCast 使用自签名证书，仅用于在局域网内加密连接。

安装并信任 LanCast CA 可以消除警告，并有助于防止中间人攻击。

下载 CA 证书

iOS / iPadOS

  1. 打开下载的文件，在 设置 → 通用 → VPN 与设备管理 中安装描述文件。
  2. 再打开 设置 → 通用 → 关于本机 → 证书信任设置，为 LanCast CA 打开完全信任。

Android

  1. 下载后打开 设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书。
  2. 选择下载的文件完成安装。不同厂商的菜单名称可能略有差异。
